## Rule

Software open hone par **sirf 2 cards** dikhni chahiye:

1. **Stock Module**
2. **ERP Module**

Baqi tamam features, tabs, registers, reports — sab kuch andar hoga usi module ke andar jahan planning document ne unhe rakha hai.

## Why

User ne explicitly kaha: "aj mein software open kero mujhe 2 cards nazar ayen — Stock Module aur doosra card ERP Module. Un ke andar baki sb cheezen hon."

## How to Apply

- Koi bhi UI screen banana ho — pehle check karo ke woh planning document mein kis module ke kis tab mein hai
- Us module ke andar usi tab mein rakho — bahar nahi
- Home/landing screen = sirf 2 module selection cards, kuch nahi
